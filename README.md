# Win7 Simu - Offline & Premium Unlocked

A 100% offline-functional and fully unlocked version of the Win7 Simu application.

Current upstream version: **4.7.0**, synchronized from the live Win7 Simu build.

Open `index.html` for local use. For packaged assets, run `npm test` and `npm run build`.
Windows, Android, and GitHub Pages builds share the same complete `dist/` output.
See [UPDATE_GUIDE.md](UPDATE_GUIDE.md) for the repeatable update workflow.

## Features
- **Removed Ads**: All ad-tracking and display mechanisms have been neutralized.
- **Premium Unlocked**: All premium themes and features are unlocked by default.
- **Offline Parity**: No network connection required.
- **Virtual Filesystem Support**: Includes local `system.zip`.
